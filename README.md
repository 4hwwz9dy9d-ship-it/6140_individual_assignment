# 小熊术前小课堂 · AR 儿童术前宣教（家庭版）

面向**儿童与家长**的术前宣教网页，配合医院的 AR 术前可视化宣教系统使用。四个页面互相跳转，手机 / 平板 / 电脑都能看。

## 页面结构

| 文件 | 内容 |
|------|------|
| `index.html` | 首页大厅：主视觉 + 三扇门入口 + 三步上手说明 |
| `kid.html` | 小朋友专区：身体小探险（6 器官热区）、冒险路线图、晚餐大作战、小勇士问答、勇气加油站、动态勋章墙（语音讲解） |
| `parent.html` | 家长专区：禁食时间计算器（2-4-6-8 规则倒推）、7 项准备清单、术后护理、FAQ、AR 效果示意 |
| `ar.html` | AR 科普手册：可操作的 AR 效果示意、30 秒演示视频、六步使用流程、安全边界、阅读证书 |

## 技术说明

- 纯静态站点，无框架、无构建、无外部 CDN 依赖，双击 `index.html` 即可本地打开
- 素材在 `assets/`：图片为 WebP（由高质量 PNG 压缩而来），视频为 H.264 MP4
- 语音讲解使用预置的「温柔小熊」配音（`assets/voice/*.mp3`，微软晓晓神经语音、语速放慢 12%），电脑 / 手机 / 微信内置浏览器音色一致；音频加载失败时自动降级为浏览器 Web Speech API
- 音频由 `语音素材/generate_voice.py` 生成，可在 `语音素材/试听小熊声音.html` 逐句试听
- `ar.html` 的「AR 效果示意」是静态插画 + SVG 标注的交互示意：器官高亮按插画比例落在颈部 / 胸口 / 上腹部，扫描框与光带仅用于提示定位，**不调用摄像头、不做真实追踪、不加载三维模型**；改造脚本见 `视觉升级/upgrade_ar.py`
- 勋章进度、清单打勾等保存在浏览器 localStorage
