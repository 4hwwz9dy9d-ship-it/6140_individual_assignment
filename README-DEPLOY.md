# README-DEPLOY.md · 小熊伙伴（真实 AI 版）

## 这一版做了什么

小熊伙伴现在接入了**真实的阿里云百炼 AI**（qwen-plus），可以真正回答孩子和家长的问题。同时：

- **API Key 只在后端服务端**，前端代码里一行都没有——GitHub Pages 是公开的，Key 放前端会被盗刷。
- 后端没部署时，聊天会**自动降级**为本地样例回复并明确标注「离线样例 · 非实时 AI」，网站照常可用，不会白屏。
- 儿童医疗安全护栏写在服务端 system prompt 里：禁食时间、用药剂量、手术方案一律引导问医护；危机情绪引导找大人；不收集隐私。
- 原有 4 个页面的功能一行都没动。

ZIP 里还有一个 `bear-ai-backend/` 文件夹，**不要上传到 GitHub**。它是 Node.js 后端，部署到阿里云函数计算 FC 3.0。详细步骤见它目录内的 `README.md`。

## 上线三步走

1. **部署后端**：按 `bear-ai-backend/README.md`，在阿里云 FC 创建函数、上传 `bear-ai-backend/` 里的代码、在环境变量里填你的 Key，拿到一个公网地址（`https://xxxx.fcapp.run`）。
2. **填地址**：把前端 `js/bear-config.js` 里的 `apiBase` 改成这个地址，连同其他前端文件上传 GitHub。
3. **等 1-2 分钟**刷新网页，小熊标题显示「AI 版 · 在线」即可真实对话。二维码不用换，网址没变。

> 想先在自己电脑上试？`bear-ai-backend/README.md` 第二节有本地运行方法，5 分钟就能看到真实效果。

## 助手功能说明

- **悬浮入口**：手机左下角；电脑右下角（AR 手册页移到右侧中部、不挡演示区）。首次进入弹气泡，约 6 秒收起，同一会话只提示一次。
- **小熊形象**：完全使用你提供的毛绒小熊（已抠图去水印），7 种状态用同一张图 + CSS 动画 + SVG 表情叠加。
- **聊天 UI**：儿童/家长双模式、文字输入、语音输入按钮、朗读按钮（浏览器本地音色，就是电脑端那个）、情绪选择、呼吸练习、清空、关闭。
- **上下文感知**：会把当前页面和正在看的器官随问题发给 AI，让它理解「这里的心脏是什么」，不记录隐私。
- **小熊语气**：不答"标准答案"，而是像小伙伴一样先接住感受，再讲一段「小熊自己也经历过…后来怎样就好了」的短故事，最后安心收尾。约 60-130 字、两三句、不分点、不啰嗦。比如问「我发烧了」，它会说「发烧的时候脑袋晕晕的，我也怕过呢。有一次我蔫蔫地趴着，护士姐姐贴了凉凉的退热贴…睡一觉我就蹦回来啦，不舒服一定要告诉大人哦」。
- **温柔声音**：点「🔊 播放」优先播放后端合成的「晓晓」温柔女声 MP3（和你之前满意的预置配音同一音色、参数一致），所有设备听到的一样；后端没有语音合成能力时自动回退到浏览器里最温柔的中文女声。语音请求走 `/api/tts`，不传 Key。
- **安全边界**：AI 回复标注「AI 生成 · 请以医护告知为准」；离线回复标注「离线样例 · 非实时 AI」。医疗护栏在服务端强制执行。

## 安全与隐私（重点）

1. **Key 已在这次对话中出现过**：建议到百炼控制台禁用并重新生成一个新 Key 用于部署。
2. **给 FC 接口设额度上限**：公开前端挡不住行家直接调接口，代码里有每 IP 限流，但还要在百炼控制台设每日预算上限（如 5 元）。
3. **CORS 白名单**：`ALLOW_ORIGIN` 填你的 GitHub Pages 域名，别用 `*`。
4. **儿童数据最小化**：对话只存浏览器内存，不落盘、不上传、不存录音；点「清空」即全清。
5. **语音**：用浏览器自带能力，微信 X5 可能不支持语音输入，但打字和朗读正常。
