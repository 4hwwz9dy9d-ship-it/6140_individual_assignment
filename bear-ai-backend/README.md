# 小熊伙伴后端 · 部署说明

这个目录让小熊伙伴接入真实的阿里云百炼 AI。前端在 GitHub Pages（纯静态、公开），**API Key 只能放在这里的服务端，绝不能写进前端**——否则任何人打开网页查看源码就能拿到 Key 并盗刷你的额度。

## 一、目录结构

```
bear-ai-backend/
├── src/
│   ├── index.js      阿里云 FC 3.0 入口（HTTP 触发器调用）
│   ├── core.js       核心逻辑：限流 + 调用百炼 + 错误处理
│   ├── prompt.js     小熊说话风格（温柔小故事哄孩子）+ 儿童医疗安全护栏
│   └── tts.js        温柔语音合成：edge-tts 晓晓音色，参数与预置配音一致
├── server.local.js   本地调试服务器（不需要 FC，直接在你电脑上跑）
├── package.json
├── .env.example      环境变量模板（不含真实 Key）
└── README.md         本文件

两个接口：
- POST /api/chat  文字对话（调百炼）
- POST /api/tts   温柔语音（本地 Python + edge-tts；FC 上若没有 edge-tts，前端自动回退浏览器温柔女声）
```

## 二、先在自己电脑上试（5 分钟）

1. 安装 Node.js 18 或更高版本（官网 nodejs.org，一路下一步）。
2. 打开命令行，进入本目录，运行（把 `你的Key` 换成你的真实 Key）：

   ```
   set BAILIAN_API_KEY=你的Key
   node server.local.js
   ```
   （Mac/Linux 用 `export BAILIAN_API_KEY=你的Key`）

3. 浏览器打开 `http://127.0.0.1:8787/index.html`，点小熊聊天即可真实对话；点「🔊 播放」听到的是后端合成的晓晓温柔音（和你之前满意的预置配音同一音色）。
   - 语音合成需要本机装了 Python 和 edge-tts（`pip install edge-tts`）。没装也不影响对话，播放会自动回退到浏览器温柔女声。
4. 测试完按 `Ctrl+C` 停止。

> 注意：这种方式 Key 只在当前命令行窗口的环境变量里，不会写进任何文件，关掉窗口就没了。

## 三、部署到阿里云函数计算 FC 3.0（让线上网站也能用）

### 步骤 1：创建函数
1. 登录阿里云控制台 → 搜索「函数计算 FC」→ 进入控制台。
2. 地域建议选**华北2（北京）**（和百炼一致，延迟低）。
3. 创建函数 → 「从零开始」/「空白函数」：
   - 函数名称：`bear-ai`（随意）
   - 运行时：**Node.js 20**
   - 触发器：添加 **HTTP 触发器**，认证方式选 **无需认证（anonymous）**
     - 说明：公开触发器本身不等于安全，安全靠下面第 3 步的环境变量 Key + 代码里的限流 + 额度上限共同保证。

### 步骤 2：上传代码
把本目录下这几个文件/文件夹打包成 ZIP 上传（FC 在线编辑器也可逐个粘贴）：
```
src/index.js
src/core.js
src/prompt.js
package.json
```
入口函数填：`index.handler`

### 步骤 3：配置环境变量（Key 放这里）
在函数配置 → 环境变量里添加：

| 变量名 | 值 | 说明 |
|---|---|---|
| `BAILIAN_API_KEY` | 你的真实 Key | **只在这里填，别的地方都不要填** |
| `BAILIAN_MODEL` | `qwen-plus` | 模型，默认即可 |
| `RATE_LIMIT` | `30` | 每 IP 每分钟最多请求次数 |
| `ALLOW_ORIGIN` | `https://4hwwz9dy9d-ship-it.github.io` | 只允许你的网站域名调用（重要，防止别人盗用） |

保存后，FC 会给出一个**公网访问地址**，形如：
`https://xxxx.cn-hangzhou.fcapp.run`

### 步骤 4：把地址填进前端
打开前端项目的 `js/bear-config.js`，找到这一行：
```js
if (typeof cfg.apiBase !== 'string') cfg.apiBase = '';
```
改成（用你自己的 FC 地址，末尾不要带斜杠）：
```js
cfg.apiBase = 'https://xxxx.cn-hangzhou.fcapp.run';
```
然后把这个文件上传到 GitHub 仓库。等 1-2 分钟，微信扫码打开网站，小熊标题显示「AI 版 · 在线」，就能真实对话了。

## 四、安全须知（重要）

1. **Key 已在你这次对话里出现过**：建议你到阿里云百炼控制台把这个 Key **禁用/轮换**生成一个新 Key，用新 Key 部署，避免泄露风险。
2. **公开前端 + CORS 挡不住行家**：`ALLOW_ORIGIN` 只能防普通网页乱调用，别人可以用命令行直接打你的接口。所以务必保留代码里的限流（`RATE_LIMIT`），并在百炼控制台设置**每日调用额度上限**，防止额度被刷爆。
3. **医疗护栏在服务端**：禁食时间、用药剂量、手术方案等决定，system prompt 里已硬性规定一律引导问医护，前端改不动。
4. **不收集隐私**：对话只在浏览器内存里，不落盘、不上传、不记录；点「清空」即全部清除。
5. **儿童数据最小化**：目前没有账号、没有数据库、不存录音，符合儿童医疗宣教网站的隐私保护原则。
6. **语音输入/朗读**：用浏览器自带能力（Web Speech API），微信 X5 内核可能不支持语音输入，但打字对话和朗读正常；朗读音色就是电脑端你喜欢的那个。

## 五、费用提示

`qwen-plus` 按量计费，这类宣教问答单次很短（几百字），一位用户聊 20 轮大约几分钱。建议在百炼控制台设置**每日预算上限**，比如 5 元，超出自动停，避免意外。

## 六、故障排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 小熊显示「离线样例」 | 前端没连上后端 | 检查 `bear-config.js` 的 `apiBase` 是否填了 FC 地址 |
| 显示「AI 版」但问了没反应 | Key 没配或额度用完 | 检查 FC 环境变量 `BAILIAN_API_KEY`，看百炼控制台额度 |
| 浏览器报 CORS 错误 | `ALLOW_ORIGIN` 没配对 | 确认填的是 `https://4hwwz9dy9d-ship-it.github.io`（不带路径、不带斜杠） |
| 回复很慢 | 冷启动 | FC 首次调用会慢几秒，之后就快了 |
